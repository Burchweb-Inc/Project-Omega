# Focus Mode wallpapers

Add `.avif`, `.jpg`, `.jpeg`, `.png`, or `.webp` images directly to this folder to list them under **Recommended**.

Create a subfolder for each collection, then add its wallpapers inside. Folder names become collection names in the picker: for example, `quiet-mornings` appears as **Quiet Mornings**. The first image alphabetically is used as the collection thumbnail.

Example:

```text
focus-backgrounds/
  sunrise.jpg
  deep-forest/
    01-canopy.webp
    02-trail.jpg
  rainy-days/
    window.png
```

Only images in the wallpaper folder itself appear under Recommended. Images in subfolders belong to that folder's collection.
